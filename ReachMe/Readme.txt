REACH ME CONTENTS 
REACH ME PAGE
==============================

PAGE PURPOSE
A separate internal webpage for contacting Parth.
It must NOT contain the Home page content.

SIDEBAR
==============================
The exact same sidebar as Home.

# HOME
# INTERESTS
# ACTIONS
# $
# PHOTOS
# REACH ME
# WRT

The sidebar must look and behave identically to the Home and WRT pages.

MAIN CONTENT
==============================

REACH ME

A simple contact section with the following:

GMAIL
------------------------------
[YOUR GMAIL ADDRESS]

CONTACT FORM
------------------------------

NAME
[Enter your name]

AGE
[Enter your age]

RELATIONSHIP
[Enter relationship]

MESSAGE
[Write your message]

[ SEND MESSAGE ]


FORM BEHAVIOUR
==============================

The visitor enters:

1. Name
2. Age
3. Relationship
4. Message

Basic validation only.

After submission:
→ Data goes to the PythonAnywhere backend.
→ Submission can be viewed through the /admin area.
→ Email notification can be sent to Parth.

No cloud database/storage requirement.

No CAPTCHA.

No unnecessary complicated anti-spam system.

SECURITY
==============================

Admin area must require authentication.

Visitors must NOT be able to access submitted messages through the public Reach Me page.

The form itself is only for submitting information.
